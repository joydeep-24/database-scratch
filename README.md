# Database from Scratch

An educational database implementation in C++,
following the Write a Database from Scratch series
by Code With Sep.

## Goals

- Understand database internals.
- Learn indexing and tree-based data structures.
- Implement database components incrementally.
- Test and document each development milestone.

## Tech Stack

- C++20
- CMake
- Git and GitHub

## Build

```bash
cmake -S . -B build
cmake --build build
